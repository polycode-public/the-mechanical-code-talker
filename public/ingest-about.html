Synthesise Facts from free text

Paste a paragraph. Each sentence it recognises becomes a triple you can export. Each sentence it does not recognise is skipped and counted, never guessed at.

What it demonstrates

This is the page that shows what tmct does with text it has never seen. Two panes: your prose on the left, the facts it grounded on the right, filling in as it reads.

The number that matters is the skip count. A run over four sentences that grounds two and skips two is reporting honestly. A tool that grounded all four would be making things up about the two it could not read.

You can drop a .txt or .md file on the left pane, or browse for one. When it is done, export the result as canonical JSONL.

One switch changes the behaviour: a fuzzy tier that will store a low confidence guess for a sentence the strict recognizer refused. Facts stored that way get their own provenance tag and the lowest trust score in the system, so they never quietly corroborate a curated fact.

Chat you can replay

The page's own sample text is chosen to include a sentence that cannot ground. Here is what it does with it.

Four sentences in, two out. A question is not a fact, and a citation marker is not part of one.

input: Zorbles are a kind of animal. How are you today? Zorbles are closely connected with wodgetry.[7]
4 sentences read, 2 grounded, 2 skipped
zorble  rdfs:subClassOf     animal
zorble  mgx:connected-with  wodgetry

Asserted in test-e2e/pages-ingest.test.mjs, which types this sample into the real page and checks the status line and both rows.

A second run extends the same store rather than replacing it. The right pane shows this run; the memory panel shows everything.

run 2: Wodgets are a kind of tool.

Asserted in test-e2e/pages-ingest.test.mjs.

With the fuzzy tier on, a sentence the strict recognizer refused is stored under its own tag.

Asserted in test-e2e/pages-ingest.test.mjs. The tag's trust prior is 0.35, defined in src/domain/memory/trust.mjs.

What it works out

The pipeline. Text splits into paragraphs on blank lines. Each paragraph splits into sentences using wink-nlp's boundary detection. Citation residue like [3] or [citation needed] is stripped. Then each sentence is tried.

Three attempts per sentence. First the whole sentence goes through the real teach lane, the same one the chat page uses. If that grounds nothing, the sentence is broken into clause candidates and each is tried. If the sentence starts with a pronoun, one retry substitutes the last subject that grounded in the same paragraph. If all three fail, the sentence is skipped and counted.

A sentence that grounds gets an ordinary teach:chat:<session>@<timestamp> tag, exactly as if you had typed it. There is no separate second-class store for ingested facts.

What it does not do. There is no scoring pass that keeps the best guess. A sentence either matches a recognised pattern or it does not. That is why the skip count is a real number rather than a leftover.

What the ask dock sees. The graph the dock queries is built from the session's own rows only, not the tens of thousands of seeded corpus facts. A term's class is its direct taxonomy parent, with no closure applied, so an unlisted class is a miss rather than an inference.

How it is built

src/services/ingest-viz.mjs renders the page. The recognizer is groundTextToFacts in src/surfaces/web/ingest-browser-entry.mjs, the browser twin of the command line's tmct extract in src/services/extract-facts.mjs.

Sentence splitting is src/services/sentences.mjs, which preserves file paths so a sentence mentioning src/a.mjs does not split on the dot.

The projected ask graph is src/domain/ingest-facts.mjs. Export is exportFactsJsonl in src/surfaces/web/memory-stats.mjs, which writes the store out as one JSON object per line.

The page keeps a best-effort snapshot in IndexedDB so a reload finds your work. Storage can be evicted, so the page treats a missing snapshot as an ordinary cold start and says so.

Next Related work

Related work

Extraction that declines is the same idea as answering that declines. These are the works behind it.

  • Attempto Controlled English, ACE 6.7, 2013.The controlled subset of English the strict recognizer reads. A sentence outside the subset is refused rather than approximated.
  • Kuhn, “A Survey and Classification of Controlled Natural Languages”, Computational Linguistics 40(1), 2014.Where ACE sits among controlled languages, and what the trade is.
  • Chow, “On optimum recognition error and reject tradeoff”, IEEE Trans. Information Theory 16(1), 1970.The skip count is a reject option applied per sentence.
  • Reiter, “On Closed World Data Bases”, in Logic and Data Bases, Plenum, 1978.Why a sentence that did not ground leaves no negative claim behind.
  • Green, Karvounarakis and Tannen, “Provenance Semirings”, PODS 2007.How the fuzzy tier's low prior stays low when a derived fact rests on it.
  • Ji et al., “Survey of Hallucination in Natural Language Generation”, ACM Computing Surveys 55(12), 2023.The failure this page is built to avoid.
