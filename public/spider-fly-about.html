Competitive multi-agent system

A spider waits in a web. A fly drifts in and weakens the longer it stays. Neither is yours to move. Each plans its own next step over the same board, and each sees only part of it.

What it demonstrates

Two agents, one board, opposed goals, and no shared view. That is the whole demonstration.

You do not play either of them. You can talk to one, and that is the interesting part: tell the spider the fly is east and it will act on what you said, whether or not you were right.

The board is ten by ten. The spider holds a web. The fly loses mass every turn it stays out. Each agent replans from scratch every tick against what it currently believes.

Sliders let you change the game while it runs: how much mass each side loses per turn, how often things spawn, and how far each can see. Widen the spider's vision and watch the chase change shape.

The spider's current plan is drawn on the board as a thread, because a plan here already is one.

The key exchange. With the fly out of range, the spider holds. Tell it where the fly is and it acts on your claim.

spider at cell-2-2, fly at cell-9-9, well out of sight
tmct> tick
nothing in sight — holding position in the web
tmct> @spider the fly is east
told the spider-1 the fly-1 is at cell-3-2
spider-1 is now at cell-3-2
co-located with fly-1

What it works out

What an agent believes. believedCellOf in src/domain/agent-belief.mjs answers where one agent thinks another is, in four rungs. A removed target is believed nowhere. A target inside the vision radius is known exactly. Otherwise the newest thing anyone told this agent about that target. Otherwise nothing.

Vision is Chebyshev distance, default radius four. There is no line of sight test. Buildings and obstacles block movement, not sight. That is deliberate: it keeps belief and the planner in agreement, so an agent never plans through a wall it can see past.

What it decides. Every tick, every agent runs the same ladder and takes the first rung that applies: deliver, carry, escape a trap, avoid a rival, chase or forage toward the nearest believed target, hold the web, or wander. The rung name is also what the status line says it is doing, so the label and the behaviour cannot drift apart.

How it plans. On the chase rung it calls the same bounded breadth-first search the Hanoi page uses, from where it is to where it believes the quarry is. If no path exists yet it falls back to a one-step greedy move. Both are recomputed from scratch every tick, so a wrong belief is corrected the moment the agent sees for itself.

What you can change. Telling an agent something writes a real fact into the store, addressed to that agent. It is not a UI hint. It is read back through the same belief function on the next tick, and it can be wrong.

What is drawn. Each creature's sprite is resolved through the real class hierarchy rather than a lookup table. Spider walks up to arachnid, then to animal, and takes the first shape the sprite set actually has.

  • spider rdfs:subClassOf arachnid
  • arachnid rdfs:subClassOf animal
  • fly rdfs:subClassOf insect
  • insect rdfs:subClassOf animal

How it is built

src/domain/spider-fly-world.mjs holds the board, the web rules and the seed taxonomy as plain constants. scripts/gen-spider-fly-world.mjs serialises them into a worlds-pack shard.

src/services/predator-prey.mjs is the tick engine. It is written against roles rather than species, so the same engine runs this page and the town square. Here spider is the predator role and fly is the prey role.

src/domain/agent-belief.mjs imports nothing at all. Belief is a pure function of the fact set and the observer, which is what makes a run reproducible.

src/services/spider-fly-turn.mjs is the chat lane: the opener, the told-fact frames, and the lane that answers questions about what an agent believes. src/services/spider-fly-viz.mjs renders the page.

Related work

Agents that act on their own beliefs, and plan under partial information.

  • Rao and Georgeff, “BDI Agents: From Theory to Practice”, 1995.Belief, desire, intention. The belief half is what this page makes visible.
  • Fikes and Nilsson, “STRIPS”, Artificial Intelligence 2(3–4), 1971.The action model behind the search each agent runs.
  • Ghallab, Nau and Traverso, Automated Planning and Acting, 2016.Planning and acting as one loop, which is what replanning every tick amounts to.
  • Molineaux, Klenk and Aha, on goal driven autonomy, 2010; Cox, “Perpetual Self-Aware Cognitive Agents”, AI Magazine 28(1), 2007, pp. 32–45.Agents that notice their plan has stopped making sense and pick a new goal.
  • Steel and Ho, Planning and Execution using Partial Decision, 1993.Kept in docs/references/planning/STEEL_AND_HO.md for planning with incomplete information.
  • Reiter, “On Closed World Data Bases”, in Logic and Data Bases, Plenum, 1978.“Nothing in sight” is not “nothing is there”. An agent that believes nothing says so.
