# 3D Models

The files in this directory are committed source assets, not generated outputs. Unlike other directories under `public/`, these models are committed to the repo because they have no generator in this codebase — they are copied from another project whose checkout does not exist in CI.

All models listed here are drawn from a closed allowlist in `data/mudiii-assets.json` and verified by `scripts/check-model-manifest.mjs`. See `CREDITS.md` for author, licence, and source information for each model.
